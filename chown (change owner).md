# chown (change owner)
---
Un comando [[Linux]] utilizzato per cambiare owner e/o gruppo a un file.

### Cambiare owner
Lanci il comando con la sintassi `chown [owner] file

es. `chown daniele file.txt`

### Cambiare gruppo
Lanci il comando con la sintassi `chown [:group] file

es. `chown :devgroup file.txt`

### Cambiare owner e gruppo
Lanci il comando con la sintassi `chown [owner][:group] file

es. `chown daniele:devgroup file.txt`
