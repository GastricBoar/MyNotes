# Soft link
---
Su [[Filesystem]], un file speciale che punta al percorso di un altro file.

Diversi filesystem supportano soft links, spaziando tra Windows, [[Linux]] e macOS.

Su Linux per esempio, un soft link è un file separato con un proprio inode; non contiene i dati del file originale, ma il suo percorso.

L’[[Hard link]] è diverso perchè punta direttamente all’inode del file, condividendone i dati.
