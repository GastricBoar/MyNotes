# SFC (System File Checker)
---
Strumento che permette a Windows di riparare i propri componenti essenziali a partire da una copia sana, archiviata localmente nel component store (WinSxS).

Nel caso in cui anche il component store fosse corrotto, potrai usare [[DISM (Deployment Image Servicing and Management)]]
