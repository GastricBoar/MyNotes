# Parity
***
In un sistema [[RAID (Redundant Array of Independent Disks)]], la parity è un'informazione matematica che ti permette di ricostruire dati persi\mancanti.

1. Il parity bit è un valore di controllo costruito dai dati distribuiti sui dischi, questo valore viene archiviato su ciascun disco assieme ai dati.

2. In caso di guasto di un disco, i dati mancanti vengono ricostruiti combinando le informazioni rimanenti e il parity bit.

Questo sistema è utile poichè ci permette di proteggere informazioni senza dover replicare i nostri dati.
