# Dictionary Attack
---
Attacco informatico in cui l'attaccante prova automaticamente una lista di password comuni o probabili, invece di provare tutte le possibili combinazioni.

### Come funziona?
L'attaccante utilizza un elenco di parole, password comuni o combinazioni frequentemente utilizzate e le prova una dopo l'altra; per esempio, se lo username è "mario" potrebbe ricorrere a "mario123", "mario2026", "password", "mario1", "mariorossi", "123456", "qwerty" etc.

È un attacco più mirato del brute-force tradizionale, perché cerca prima tra le password più probabili.

### Come si previene?
La difesa principale consiste nell'impedire che password comuni o prevedibili possano essere utilizzate e nel limitare i tentativi di autenticazione:

- Password lunghe e uniche.

- Blocco o rallentamento dopo diversi tentativi falliti.

- MFA.

- CAPTCHA.

- Blocklist delle password per impedire l'uso di password comuni.
