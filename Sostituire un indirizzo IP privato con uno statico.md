# Sostituire un indirizzo IP privato con uno statico
***
Ci sono dei casi particolari (adesso non ne conosco nessuno) in cui può essere utile che il PC prenda un indirizzo statico piuttosto che un indirizzo privato, nel caso in cui il server [[DHCP (Dynamic Host Configuration Protocol)]] abbia dei problemi.

In Windows puoi configurare questa cosa così:

1. Apri pannello di controllo alla sezione reti.
2. Seleziona la tua scheda di rete.
3. Apri le proprietà relative al protocollo IPv4.
4. Apri la scheda di configurazione alternativa e compila quello che ti serve:
