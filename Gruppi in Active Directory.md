# Gruppi in Active Directory
---
I gruppi [[Active Directory]] riuniscono risorse di vario tipo, sono dei contenitori logici; raggruppano cose come persone, computer, o altri gruppi.

#### **Security groups e distribution groups**
Due diversi tipi di gruppi:

- Il primo si usa per assegnare permessi ([[NTFS (New Technology File System)]], policy, condivisioni in rete).
- Il secondo si usa per distribuire liste di mail.
