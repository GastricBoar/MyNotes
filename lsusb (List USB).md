# lsusb (List USB)
---
Comando Linux utilizzato per elencare i dispositivi collegati al bus USB del sistema, come tastiere, mouse, webcam e adattatori di rete USB.

Potrebbe non essere presente per impostazione predefinita, in questo caso lo installi con `sudo dnf install usbutils`
