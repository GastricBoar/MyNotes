# cleanmgr (Disk Cleanup)
---
Un comando Windows che libera spazio dal disco. Lo fa eliminando file come log di errori, file temporanei, cache thumbnail o di sistema, file di aggiornamenti scaricati etc.

Lo avvii scrivendo "cleanmgr" da pannello "Esegui".
