# robocopy (Robust File Copy)
---
Strumento a riga di comando di Windows, pensato come successore del comando [[xcopy (Extended Copy)]].

Integra una serie di funzionalità avanzate, per esempio: copia ricorsiva delle cartelle, sincronizzazione (`/MIR`), ripresa delle copie interrotte (`/Z`) e conservazione di permessi e attributi NTFS (`/COPYALL`)
