# API (Application Programming Interface)
---
Insieme di regole e protocolli che permettono a diversi sistemi software di comunicare tra di loro senza conoscerne i rispettivi funzionamenti interni.

### Come funziona?
Per fare un esempio:

- Vuoi visualizzare le previsioni del tempo, e usi un app per il meteo.
- L'app non elabora le previsioni da zero sul tuo cellulare, ma invia una richiesta a un server che ospita un servizio meteo.
- Questo server ha un'API che consente all'app di chiedere "Qual è il meteo di oggi a Milano?".
- Il server risponde con i dati meteo che l'app poi visualizza all'utente.
