# su (Substitute User)
---
Comando [[Linux]] utilizzato per cambiare utente nella sessione corrente, senza effettuare il logout.  
  
### Passare a un altro utente  
Lanci il comando con la sintassi `su [utente]`  
  
es.  
  
```bash  
su mario  
```  
 
### Passare all'utente root  
Lanci il comando con la sintassi `su`  
  
oppure  
  
```bash  
su root  
```
