# UUID (Universally Unique ID)
---
In informatica è un identificatore univoco, può essere assegnato a cose più disparate: filesystem di un disco storage, partizioni, ID utenti, token, sessioni, database, container, snapshot, dispositivi USB, schede di rete, bus interni, servizi di sistema.

Per fare un esempio: a ciascun file system di un disco storage viene assegnato un UUID, questo non cambia mai anche se quel disco lo sposti in un altro PC; cambia solo se formatti il disco.

In esempio concreto nella vita di tutti i giorni: dire "la macchina che occupa il secondo posto del parcheggio" è diverso da dire "la macchina con quel numero di telaio ben preciso".
