# Immagine ISO
---
Un file che contiene una copia identica (immagine) di un disco.

Logicamente, è come stessi inserendo un disco dentro il lettore ottico del PC, ma in formato file.

### Montare una ISO
Quando monti una ISO il [[Sistema operativo]] la legge come disco virtuale.

Qui due scenari:

- se vuoi navigare i file della ISO, la monti e ci guardi dentro.
- se vuoi far qualcosa tipo installare una distro [[Linux]], usi il Balena Etcher\Rufus\Ventoy di turno e la rendi bootabile.
