# Windows Server
---
Volessi gestire un server DNS sul mio Windows Server, dovrei selezionare la voce "Server DNS" all'interno del Server Manager. Il termine che Windows Server utilizza per questo tipo di cose non è "funzionalità", ma "ruoli", perchè ideologicamente è come stessi assegnando un ruolo o un compito professionale al tuo server.
