# mount (mount filesystem)
---  
Comando [[Linux]] utilizzato per collegare un [[Filesystem]] a una cartella dell'albero directory.
  
### Uso di base  
Lanci il comando con la sintassi mount [dispositivo] [mount point]  

es. `mount /dev/sda1 /mnt/HDD_WD_Red`

Allo stesso modo, il comando inverso per smontare il dispositivo è: `unmount /dev/sda1 /mnt/HDD_WD_Red`
