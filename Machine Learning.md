# Machine Learning
---
Il machine learning è una sotto-disciplina dell'[[Intelligenza artificiale (AI)]] che permette alle macchine di estrarre informazioni dai dati e apprendere da loro in maniera autonoma.

Non è da confondere con l'intelligenza artificiale (vedi [[Differenza tra intelligenza artificiale e machine learning]])
