# Host file
***
Un file di configurazione presente su ogni sistema operativo, associa manualmente dei nomi di dominio a un [[Indirizzo IP (Internet Protocol)]].

È il precursore del [[DNS (Domain Name Server)]], ma attenzione perchè questo file esiste ancora tutt'oggi ed è la prima verifica fatta dal sistema nell'accedere a un dominio: se la risoluzione adatta non viene rintracciata nel file host, si passa al DNS.

###### **Dove si trova?**
in **Windows** è in `C:\Windows\System32\drivers\etc\hosts`, in **Linux** e **macOS** è in `/etc/hosts`.
