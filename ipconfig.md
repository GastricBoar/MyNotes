# ipconfig
***
Comando utilizzato su sistemi operativi Windows, ti aiuta a diagnosticare e risolvere problemi di rete.
###### **Esempi di utilizzo** 

`ipconfig`: visualizza le informazioni di rete di base.

`ipconfig /all`: visualizza informazioni dettagliate, come indirizzi MAC e impostazioni DHCP/DNS.

**`ipconfig /release`** : rilascia l'indirizzo IP corrente, utile per rinnovare la configurazione.

`ipconfig /renew`: richiede un nuovo indirizzo IP al server [[DHCP (Dynamic Host Configuration Protocol)]].

**`ipconfig /flushdns`**: cancella la cache del DNS per risolvere problemi di risoluzione dei nomi.
