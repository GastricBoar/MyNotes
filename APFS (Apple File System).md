# APFS (Apple File System)
---
[[Filesystem]] introdotto da Apple nel 2017, successore di [[HFS (Hierarchical File System)]]

### Quali sono le caratteristiche principali?
Lo standard per dispositivi Apple, ha snapshot nativi, crittografia, [[CoW (Copy-on-Write)]], ed è pensato come sistema SSD-first.

È pensato per essere sicuro, flessibile, veloce.
