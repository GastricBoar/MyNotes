# cd (Change Directory)
---
Comando [[Linux]] utilizzato per cambiare la directory di lavoro corrente.  
  
### Spostarsi in una directory  
Lanci il comando con la sintassi `cd [directory]`  
  
es.  
  
```bash  
cd /home/mario/Documents  
```  
  
### Tornare alla home dell'utente  
Lanci il comando con la sintassi `cd`  
  
oppure  
  
```bash  
cd ~  
```  
  
### Tornare alla directory precedente  
Lanci il comando con la sintassi:  
  
```bash  
cd ..  
```  
  
### Tornare alla directory visitata in precedenza  
Lanci il comando con la sintassi:  
  
```bash  
cd -  
```
