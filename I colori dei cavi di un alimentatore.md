# I colori dei cavi di un alimentatore
***
I cavi di un [[PSU (alimentatore)]] seguono uno schema di colori standard a seconda della loro tensione o della loro funzione:

| Colore    | Tensione / funzione                                      |
| --------- | -------------------------------------------------------- |
| Giallo    | +12V (per CPU, GPU, ventole)                             |
| Rosso     | +5V (per periferiche e unità di archiviazione)           |
| Arancione | +3.3V (per chipset, RAM e altri circuiti)                |
| Nero      | Terra (Ground)                                           |
| Verde     | PS_ON (accende l’alimentatore)                           |
| Grigio    | PWR_OK (segnale di ok dell’alimentazione)                |
| Blu       | -12V (per alcuni dispositivi legacy)                     |
| Viola     | +5V Standby (fornisce energia quando il PC è spento)<br> |
