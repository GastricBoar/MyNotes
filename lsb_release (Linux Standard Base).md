# lsb_release (Linux Standard Base)
---
Comando Linux utilizzato per visualizzare informazioni sulla distribuzione Linux installata.

### Come funziona?
LSB sta per "Linux Standard Base", uno standard nato per favorire la compatibilità tra distribuzioni Linux.

Su alcune distro potrebbe mancare per impostazione predefinita, lo trovi soprattutto su distro Debian-based.

#### lsb_release -a (all)
Visualizza tutte le informazioni disponibili sulla distribuzione Linux, tra cui nome, descrizione, e versione.

Lanci il comando:

```bash
lsb_release -a
```
