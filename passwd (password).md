# passwd (password)
---
Comando [[Linux]] utilizzato per modificare e gestire password degli utenti.

### Cambiare la propria password
Lanci il comando con la sintassi `passwd` e basta.

### Cambiare la propria password di un altro utente
Lanci il comando con la sintassi `passwd [utente]`

es. `passwd mario`
