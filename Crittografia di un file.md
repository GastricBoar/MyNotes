# Crittografia di un file
***
La crittografia in informatica è una tecnica che permette di proteggere i dati archiviati su un'unità di memoria, il file da crittografare viene codificato tramite una chiave di crittografia e decodificato al bisogno.

Crittografare un file ci permette di proteggere i nostri dati in scenari del genere: 

>Su un computer condiviso sono stati aggiunti più account utente, se uno degli utenti cercherà di accedere al mio file crittografato a partire dalla sua utenza non ci riuscirà.

Su Windows è possibile crittografare un file tramite la tecnologia [[EFS (Encrypting File System)]], ma ogni sistema operativo ha il suo strumento per eseguire crittografia di files.

Questo meccanismo ci proteggerà solo se non abbiamo ancora effettuato il log-in al nostro account; nel momento in cui ci connettiamo alla nostra utenza, tutti i file crittografati vengono decifrati.

Per crittografare un file in Windows: tasto destro > avanzate > "crittografa contenuto per proteggere i dati"
