# Ceph
---
Uno storage distribuito tra più server [[Proxmox]]. 

Da GUI vedresti un unico grande spazio di storage, invece che tanti dischi separati. Replica automaticamente i dati tra i server (nodi) che ne fanno parte, e se uno dei server scoppia ti ritrovi il contenuto già pienamente operativo sugli altri server.
