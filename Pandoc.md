# Pandoc
---
Pandoc è uno strumento di conversione per documenti di testo, è open-source e supporta una vasta di formati in input e output come Markdown, HTML, LaTex. PDF, Word, ePUB e altro.

Può essere utilizzato manualmente per convertire files da un formato all'altro, oppure può essere integrato in flussi di lavoro (come script bash, Powershell etc.) per automatizzare la conversione di files.
