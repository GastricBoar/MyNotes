# XFS (Extended File System)
---
[[Filesystem]] sviluppato dalla Silicon Graphics negli anni '90.

### Quali sono le caratteristiche principali?
Progettato per grandi volumi di dati (fino a 8 EB), è il filesystem di default per le distribuzioni Red Hat Enterprise, CentOS, Alma e Rocky.

È stabile, efficiente e scala bene su grandi storage; per uso generale è meglio [[ext4 (fourth extended filesystem)]].
