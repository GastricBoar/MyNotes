# ICMP (Internet Control Message Protocol)
***
Un [[Protocollo]] di rete, utilizzato nell'insieme di protocolli [[TCP IP (TCP over IP)]]. 

A differenza dei protocolli [[TCP (Transport Control Protocol)]] e [[UDP (User Datagram Protocol)]], l'ICMP non è pensato per trasmettere dati, ma per verificare lo stato della rete tramite l'invio di un singolo pacchetto, il ping.
