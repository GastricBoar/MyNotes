# uname (Unix Name)
---
Comando [[Linux]] utilizzato per visualizzare informazioni sul sistema operativo e sul kernel.

### Visualizzare il nome del sistema
Lanci il comando con la sintassi:

```bash
uname
```

Per impostazione predefinita mostra il nome del kernel.

### uname -a (All)
Visualizza tutte le informazioni disponibili sul sistema.

Lanci il comando con la sintassi:

```bash
uname -a
```

### uname -r (Kernel Release)
Mostra la versione del kernel in uso.

Lanci il comando con la sintassi:

```bash
uname -r
```

### uname -m (Machine)

Mostra l'architettura della macchina.

Lanci il comando con la sintassi:

```bash
uname -m
```

### uname -n (Node Name)
Mostra il nome host del sistema.

Lanci il comando con la sintassi:

```bash
uname -n
```
