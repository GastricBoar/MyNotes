# xcopy (Extended Copy)
---
Strumento a riga di comando di Windows, pensato come versione avanzata del comando copy, che copiava solo file e gestiva male le directory.

Oggi è uno strumento legacy, il successore ne è [[robocopy (Robust File Copy)]].
