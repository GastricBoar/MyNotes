# Samba
---
Un software open source per sistemi Linux e Unix, implementa i protocolli di rete di Microsoft (SMBv2/SMBv3).

Con Samba installato, una macchina Linux può funzionare sia da server (condividendo cartelle e stampanti per PC Windows e Mac) sia da Client (accedendo alle cartelle di rete di Windows).
