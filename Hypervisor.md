# Hypervisor
---
Un particolare tipo di software necessario alla [[Virtualizzazione]] di una macchina.

Ne esistono due tipi:

- **Type 2:** un'applicazione installabile su sistema operativo, in questo caso tra le VM e l'hardware vero e proprio c'è lo strato di mezzo composto dal sistema operativo stesso. Esempi di hypervisor type 2 sono Oracle Virtualbox, VMware Workstation, VMware Fusion, KVM e Xen (entrambi parte della virtualizzazione su sistema linux CentOS).
  
- **Type 1**: il componente per la virtualizzazione viene installato ed eseguito senza bisogno di un sistema operativo di mezzo. Alcuni esempi di hypervisor type 1 sono: VMware vSphere/ESXi, Microsoft Hyper-V, RHEV (Red Hat Enterprise Virtualization), Citrix (XenServer). Se vuoi approfondire sull'installazione di un hypervisor di questo tipo, ecco un [video](https://www.youtube.com/watch?v=apC1bOLbzbY) a riguardo.
