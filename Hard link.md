# Hard link
---
Su [[Filesystem]], un nome aggiuntivo per lo stesso file.

Diversi filesystem supportano hard links, spaziando tra Windows, [[Linux]] e macOS.

Su Linux per esempio, un singolo inode può avere più nomi; non sono copie, sono nomi che puntano allo stesso file.

Il [[Soft link]] è diverso perchè non punta al file, ma è un file separato (con un suo inode) che punta al percorso del file originale.
